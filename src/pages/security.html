Your data never leaves your servers.

This page is for the person who has to say yes: what fein touches, where it runs, and how to check each claim.

Six guarantees, each one checkable.

The code that makes each one true is public.

  • Always self-hosted.

    fein runs on infrastructure you control and sends nothing to us.

  • Open source, end to end.

    Every line that touches your data is public, under Apache 2.0. Audit it before you run it.

  • One token, every surface.

    The dashboard, the API, and the agent endpoint sit behind the same gate.

  • Private by person.

    Each person’s sensitive sources stay in their own layer inside the shared graph, and fein enforces that scoping in every query. Personal data is masked as it is read, before a fact is stored or sent to a model.

  • Every change is written down.

    Ingests, merges, and review decisions are logged to an append-only audit trail, with the person or agent that made each one.

  • Nothing phones home.

    No telemetry, no analytics, no control plane of ours. Disconnect from the internet and fein carries on answering.

What fein reads, and where it stays.

fein connects to the systems your firm already runs: email, calendar, files, notes, and CRM. The graph it builds, with its full history, lands in your own database.

The deployment surface.

  • →Runs where you say. A machine you own, on-prem or in your own cloud account, deployed with Docker.
  • →Credentials stay yours. Your admin grants credentials for each source. Revoke one and that source goes dark to fein.

What security reviews ask.

Does our data ever reach fein the company?

No. Nothing leaves your environment, not even telemetry. On a managed setup, our engineer works in your infrastructure with access you can end at any time.

How do we verify any of this?

Read the code. The source is on GitHub, and the binary you run is built from it, so you can review before anything is deployed.

How is access controlled inside the firm?

One token gates the dashboard, the API, and the agent endpoint. Each person’s sensitive sources sit in a private layer that every query respects, human or agent.

Is there an audit trail?

Yes. Every ingest, merge, and review decision lands in an append-only trail with the person or agent that made it. A fact that stops being true is struck, dated and kept.

What happens to the data if we cancel or you disappear?

Nothing. The licence cannot be revoked, the graph is in your own database, and there is no kill switch or expiry. A cancelled contract stops the upkeep, not the system.
